# 瞬時最大給水流量計算ツール

給水負荷単位（WU: Water Unit）法に基づき、建物の瞬時最大給水流量を算定するツールです。器具の台数をエリアごとに入力し、ハンター曲線を用いて瞬時最大給水流量（L/min）を求めます。公衆用・私室用の区分で別々に算定し、洗浄弁多い場合・洗浄タンク多い場合の両曲線の結果を表示します。

## ⚙️ 操作手順

1. **エリア追加**：「＋ エリア追加」ボタンでエリア（階・ゾーン等）を追加します。
2. **器具台数入力**：各エリアのアコーディオンを開き、器具ごとに台数を入力します。＋／－ボタンまたは直接数値入力が可能です。
3. **結果確認**：結果タブ（PCは右カラム）でエリア別WU集計・瞬時最大給水流量・器具別集計を確認します。
4. **設定**：設定タブで器具マスタの内容確認・編集、ハンター曲線テーブルの参照ができます。
5. **データ保存・読込**：JSON出力でエリアデータを保存し、JSON読込で復元できます。CSV出力も可能です。
6. **サンプルデータ**：「📋 サンプルデータ読込」でオフィスビル5エリアのサンプルデータを読み込みます。

## 🔢 計算フロー

### 負荷単位（WU）集計

各器具の台数に負荷単位原単位（WU/台）を掛けて合計します。公衆用・私室用を別々に集計します。

```
合計WU（公衆用） = Σ（器具i の 公衆用WU × 台数i）
合計WU（私室用） = Σ（器具i の 私室用WU × 台数i）  ※ 私室用なし器具は除く
```

### 瞬時最大給水流量

合計WUをハンター曲線に入力し、瞬時最大給水流量を求めます。洗浄弁系とタンク系の2曲線を算出します。

```
瞬時最大給水流量（洗浄弁多い場合） = HunterCurve1（合計WU）  [L/min]
瞬時最大給水流量（タンク多い場合） = HunterCurve2（合計WU）  [L/min]
```

## 📈 ハンター曲線（区分線形補間）

SHASE-S206（図5.56）に基づく区分線形補間テーブルを使用します。

| WU範囲 | データ出典 |
|---|---|
| WU ≦ 10 | Hunter 原典値 |
| WU = 11 〜 250 | SHASE-S206 拡大図(b) 読み取り |
| WU > 250 | SHASE-S206 全体図(a) 読み取り |
| WU > 3000 | 末尾2点から線形外挿 |

区間補間式：

```
Q = Q1 + (WU − x1) × (Q2 − Q1) / (x2 − x1)
```

> 各水道局が独自のHunter曲線早見表を公開している場合があります。所轄水道局の指針がある場合は、本ツールの算定値を参考値として、所轄水道局の基準に従って流量を読み取ってください。

## 🗂️ 器具マスタ管理

### 組み込みマスタ（🔒）

削除・上書き不可。読込のみ可能です。

| マスタ名 | 出典 |
|---|---|
| SHASE | SHASE-S206 |
| 京都市水道局 | 給水装置工事設計施工指針（表9 給水用具給水負荷単位表） |
| 大阪市水道局 | 水道施設設計指針（表2-19 給水用具給水負荷単位） |

### カスタムマスタ

- 「別名保存」で現在の器具リストに名前をつけてブラウザの localStorage に保存できます（複数作成可）。
- 「上書き保存」はカスタムマスタへの上書き（組み込みマスタには使用不可）。
- 「📂 読込」のマスタ一覧モーダルで、カスタムマスタのロード・リネーム・削除が可能です。
- JSON出力／読込でブラウザや PC 間のマスタ移行ができます。

> 未保存状態では「未保存」バッジが表示され、カードが青枠になります。

---

## ⚠️ 孤立器具について

マスタを切り替えた際、新マスタに存在しない器具は **赤字** で「マスタ未登録・WU除外」と表示され、WU計算から除外されます。「置き換え」ボタンで現在のマスタの器具に置き換えるか、新規器具として追加できます。

## 📋 注意事項

- 洗浄弁多い場合／洗浄タンク多い場合のいずれを採用するかは設計者の判断によります。
- ハンター曲線はグラフ読み取り値のため、±数 L/min 程度の誤差があります。精密設計時は SHASE-S206 数表との照合を行ってください。
- 本ツールの計算値は一般設計用途を目的としています。
