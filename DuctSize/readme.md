# ダクトサイズ選定（DuctSize）

風量からダクトサイズ（丸・角）と吹出・吸込口サイズを選定する単一HTMLツールです。

## 画面構成
| タブ | 内容 |
|---|---|
| ダクトサイズ | 摩擦損失・風速の上限からダクトサイズ候補を表示。選択サイズの特性を表示 |
| 吹出・吸込口 | 開口率・面風速から必要面積とサイズ候補を表示。台数割り対応 |
| 計算根拠 | 計算式・材質の粗さ一覧 |

## 主な機能
- 風量の単位切替（m³/h ⇔ m³/min ⇔ L/s）と四則演算入力（例 `1200*3+800`）
- 選定スタイル（初期値：標準（低速）・高速（排煙）・コンクリート・グラスウールの [Pa]／[mmAq] 版、引抜鋼管 [Pa]／[mmAq]、塩ビ・ステンレス [Pa]、低騒音・高速・排煙。名前変更・追加可。スタイルごとに圧力単位を保持）
- 材質（粗さ ε）の切替：亜鉛鉄板・ステンレス・塩ビ・グラスウールダクト・フレキシブル・コンクリート・引抜鋼管・その他（ε 直接入力）
- 高さ上限・アスペクト比上限による角ダクト候補の絞り込み（天井懐が厳しいとき用）
- 選択ダクトの情報（未選択時は先頭の角サイズを自動表示）：風速・摩擦損失（上限判定の色分け）・動圧・相当直径・丸ダクト換算時風速・基準風量・断面積・基準風量比・保温込みの外形寸法
- 圧力単位の切替（Pa ⇔ mmAq）
- 吹出・吸込口：器具プリセット・台数割り（メイン画面の −／＋ で増減）・必要台数・有効開口の面風速
- メモリ：各画面の情報カードの下に、名前を付けて風量・スタイル（条件）・サイズを記録。行タップで呼び出し、名前タップで変更、左スワイプ（PC は右クリック）で表示される「削除」で削除、全コピー（Excel 用タブ区切り）
- 候補一覧・情報のコピー（Excel 貼り付け用のタブ区切り）
- ⚙ の設定ダイアログで選定スタイル（ダクト：材質・内面粗度・最大風速・摩擦損失・アスペクト比／吹出口：開口率・面風速・アスペクト比）の新規作成・名前変更・削除。「保存」でスタイルに記録して適用、「適用」は計算のみに反映
- 設定はブラウザ（localStorage）に保存。⚙ の「書き出し」で JSON ファイルに保存、「読み込み」で復元、「初期化」で初期状態に戻す

## 計算式
- 摩擦損失：Darcy–Weisbach ＋ Colebrook（ρ=1.2 kg/m³、ν=15.1×10⁻⁶ m²/s）
- 角ダクトの相当直径：`De = 1.30·(W·H)^0.625 / (W+H)^0.25`
- 吹出・吸込口：`有効面積 = Q/(3600·v)`、`必要面積 = 有効面積/開口率`
