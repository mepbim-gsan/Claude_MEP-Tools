# IFC Viewer

複数の IFC モデルを重ねて表示し、3D・2D平面・プロパティ一覧・集計・差分比較を行うビューアです。
単一 HTML（`index.html`）で動作し、ライブラリと WASM を埋め込んでいるため**ネット接続なし（社内ネットワーク）でも使えます**。

## ファイル構成

| ファイル | 説明 |
|---|---|
| `index.html` | ツール本体（ビルド成果物・単一ファイル・約6MB） |
| `src/app.js` | ソース（three.js + web-ifc） |
| `src/template.html` | HTML / CSS テンプレート |
| `build.mjs` | `index.html` を生成するビルドスクリプト |

## 使い方

1. `index.html` をブラウザ（Chrome / Edge）で開く
2. 「IFCを開く」で選択するか、画面にドラッグ＆ドロップ（複数ファイル可、順次追加）

| 機能 | 操作 |
|---|---|
| 3D | 左ドラッグ: 回転 ／ 右ドラッグ: パン ／ ホイール: ズーム ／ クリック: 選択 ／ Ctrl・Shift+クリック: 複数選択 ／ ダブルクリック: 選択にズーム ／ F: 全体表示 ／ Esc: 選択解除 |
| 2D平面 | 「階・2D」タブで階と表示範囲（床からの高さ）を指定。真上から表示し、IfcSpace の部屋名（番号・名称・任意プロパティ）をラベル表示。切断面は濃いグレーで塗りつぶし |
| モデル | 表示切替・モデル単位の全体表示・閉じる。作成アプリ（Revit / Rebro 等）・スキーマ・要素数を表示 |
| 系統 | 判定キー（IfcSystem または任意プロパティ。既定は自動判定）ごとに一覧・表示切替・選択・色分け |
| 分類 | IFC クラスごとの表示切替・選択 |
| 色分け | 元の色 / モデル別 / IFCクラス別 / 系統別 / 階別 / 任意プロパティ値別 / 差分 |
| 一覧 | 要素をモデル横断で一覧。列にプロパティを追加、並べ替え、絞り込み、CSV 出力 |
| 集計 | 行=任意キー、列=モデルの件数・合計表。セルクリックで該当要素を選択 |
| 差分 | 旧・新モデルを GlobalId で対応付け、追加・削除・プロパティ変更を一覧・3D色表示・CSV 出力 |

- プロパティキーの「（全Pset） / プロパティ名」は Pset 名を問わず同名プロパティを拾います（Revit のバージョン違いで Pset 名が異なるモデル同士の比較用）
- 集合要素（屋根・カーテンウォール等）の部品は、親要素のプロパティも表示・参照します

## 制約

- 大容量ファイル（数百 MB）は読み込みに時間がかかり、メモリを多く使います（ブラウザの WASM メモリ上限 4GB）。64bit 版 Chrome / Edge 推奨
- 形状生成中は画面が一時的に固まることがあります。プロパティ索引は読み込み後にバックグラウンドで作成します
- 2D 平面は切断表示であり、図面としての線種・ハッチングは表現しません

## ビルド

```
npm install
node build.mjs
```
