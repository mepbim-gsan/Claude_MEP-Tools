# IFC Analyzer

IFC がタイプを使って構成されているか、インスタンスごとに情報を持っているかを分析します。
形状を生成しないため、大容量ファイルでも IFC Viewer より軽く動作します。単一 HTML（`index.html`）でオフライン動作します。

## 使い方

1. `index.html` を Chrome / Edge で開く
2. 「IFCを開く」で選択するかドラッグ＆ドロップ（複数可・横に並べて比較）
3. 各タブの表を「CSV出力」で保存

| タブ | 内容 |
|---|---|
| 概要 | モデルごとの判定と主要指標（複数モデルを横に並べて比較） |
| ① タイプ | クラス別のタイプあり率・タイプ数・1タイプあたり要素数 ／ タイプ一覧（未使用タイプの確認） |
| ② 形状 | クラス別の Mapped（共有形状）・独自形状・再利用率 ／ 表現種別（SweptSolid / Brep / Mapped→… 等） |
| ③ プロパティ | タイプ側・インスタンス側のプロパティ量、Pset 実体の共有率、タイプと同値のインスタンスプロパティ |
| ④ 重複候補 | 同じタイプの全インスタンスで同じ値なのに、要素ごとに別実体で出力されているプロパティ |
| ⑤ 容量 | 分類別（形状・プロパティ・関係・配置・表現スタイル）／エンティティ別のバイト数 |
| ⑥ 出力情報 | スキーマ・ビュー定義・エクスポータ・出力元・単位（作成者・組織は表示しない） |

## 判定基準

| 判定 | 条件 |
|---|---|
| タイプ構成（形状もタイプで共有） | タイプあり率 80% 以上 かつ Mapped率 50% 以上 |
| タイプ構成（形状はインスタンスごと） | タイプあり率 80% 以上 かつ Mapped率 50% 未満 |
| 混在 | タイプあり率 20〜80% |
| インスタンス構成（形状は共有） / フルインスタンス構成 | タイプあり率 20% 未満（Mapped率で区別） |

- 対象要素は IfcElement の派生（開口・仮想要素は除外）
- 形状は Body 表現（なければ Axis / Box 等以外の表現）で判定
