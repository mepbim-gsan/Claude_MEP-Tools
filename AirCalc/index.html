📋 使い方

  • 7項目のうち 任意の2つ に値を入力すると、残りが自動計算されます
  • 露点温度（DP）は単独入力でも絶対湿度（W）を即時算出できます。もう1つ入力すれば全項目が揃います
  • 3つ以上入力すると他の欄がロックされます。1つ消すと解除されます
  • マイナス値（氷点下など）は −15℃ まで入力できます
  • 入力欄で 四則演算式（例：26+2、(35+28)/2）を入力してフォーカスを外すと自動計算されます。スマートフォンでは入力欄の下に演算子ボタンが表示されます
  • 計算後に「履歴に保存」を押すとその状態を記録できます
  • 高地や特殊環境では大気圧を変更してください（例：800m≒92 kPa）

📊 空気線図・比較チャート

  • 計算タブの下部に 空気線図 をリアルタイム表示します。計算結果の状態点を●でプロットします
  • 履歴タブでは保存した条件を最大5点まで選択して 比較チャート に重ねてプロットできます（①〜⑤で色分け表示）
  • 履歴アイテムをタップして選択・解除できます。番号はタップした順に付与されます
  • 比較チャートの点をタップすると、その条件の詳細がツールチップで表示されます
  • 空気線図・比較チャートともに 長押し / ダブルクリックで画像保存 できます

🔢 計算式・計算根拠

① 飽和水蒸気圧　pₛ [kPa]
Buck方程式（ASHRAE推奨に準拠）を使用：

pₛ(T) = 0.61121 × exp( (18.678 − T/234.5) × T/(257.14 + T) ) T : 乾球温度 [℃]

② 絶対湿度　W [kg/kg']

pv = RH/100 × pₛ(DB) ← 実水蒸気分圧 W = 0.62198 × pv / (P − pv) ← P:大気圧[kPa]

③ 相対湿度　RH [%]

pv = W × P / (0.62198 + W) RH = pv / pₛ(DB) × 100

④ 露点温度　DP [℃]
実水蒸気分圧 pv を求め、pₛ(T)=pv となる T を Newton法で逆算。
逆方向（DP→W）は大気圧だけで一意に決まるため、DP単独入力でWを即時算出可能：

W → DP: pv = W×P / (0.62198+W), DP = pₛ⁻¹(pv) ← Newton法 DP → W: pv = pₛ(DP), W = 0.62198×pv / (P−pv) ← 直接計算

⑤ 比エンタルピー　h [kJ/kg]
JIS B 8628 / ASHRAE Fundamentals準拠：

h = 1.006×DB + W×(2501 + 1.86×DB) ↑乾き空気顕熱 ↑水蒸気潜熱 ↑水蒸気顕熱

⑥ 湿球温度　WB [℃]
簡略Sprung式（温度補正項を省略）を使用。DB・W が既知のとき WB を二分法で求解：

W = Wₛ(WB) − A × (DB − WB) Wₛ(WB) : WBにおける飽和絶対湿度 A = 0.000412 [1/℃] ← Cpa/λ ≒ 1.006/2501 に相当 DB,W が既知のとき DP ≤ WB ≤ DB の範囲を二分法で求解

⑦ 比容積　v [m³/kg]
理想気体の状態方程式から：

v = 0.2871×(DB+273.15)×(1 + 1.6078×W) / P 0.2871 : 乾き空気のガス定数 Ra/1000 [kJ/(kg·K)] 1.6078 : Ra/Rv = 287.058/461.5

⑧ 逆算・特殊ケース
DB以外の2変数が既知の場合、二分法（bisection）で DB を求めた後、上記①〜⑦を適用します。探索範囲は −30〜80℃。
DP単独の場合は DP→W の直接変換（大気圧のみで決まる）を行います。

⚠ 本ツールの計算精度について
飽和水蒸気圧はBuck方程式（誤差 <0.01%）、湿球温度は簡略Sprung式（A=0.000412、参照ソフト値と±0.02℃以内で一致）を使用しています。 精密な空調設計では ASHRAE Handbook of Fundamentals または JIS B 8628 の数表との照合を推奨します。
