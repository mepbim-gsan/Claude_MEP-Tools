# 湿り空気計算ツール（AirCalc）

湿り空気の7つの物理量を相互変換する計算ツールです。任意の2項目を入力すると残りの全項目が自動算出されます。計算結果はリアルタイムで空気線図にプロットされ、履歴に保存して複数条件を比較チャートで可視化できます。

## ⚙️ 操作手順

1. **大気圧設定**：上部の「大気圧」欄で気圧を設定します（デフォルト：101.325 kPa）。高地や特殊環境では変更してください（例：標高800m ≒ 92 kPa）。
2. **値の入力**：7項目のうち任意の2つに値を入力すると、残りの項目が自動計算されます。
3. **露点温度の単独入力**：DP（露点温度）を1つだけ入力した場合、絶対湿度（W）を即時算出できます。もう1項目入力すれば全項目が揃います。
4. **四則演算入力**：入力欄に `26+2` や `(35+28)/2` のような式を入力してフォーカスを外すと自動計算されます。スマートフォンでは入力欄の下に演算子ボタンが表示されます。
5. **マイナス値**：−15℃ までの氷点下温度を入力できます。
6. **履歴保存**：計算完了後に「📋 履歴に保存」を押すと現在の状態を記録します。
7. **3つ以上の入力**：3つ以上入力すると空欄がロックされます。1つ削除するとロックが解除されます。

## 🌡 各物理量の定義

| 記号 | 名称 | 単位 | 説明 |
|---|---|---|---|
| DB | 乾球温度 | ℃ | 通常の温度計で測る気温 |
| RH | 相対湿度 | % | 飽和水蒸気量に対する実際の水蒸気量の割合 |
| W | 絶対湿度 | kg/kg' | 乾き空気1 kgに含まれる水蒸気の質量 |
| DP | 露点温度 | ℃ | 空気を冷やしたとき結露が始まる温度（RH=100%となる温度） |
| h | 比エンタルピー | kJ/kg | 乾き空気1 kgあたりの全熱量（顕熱＋潜熱） |
| WB | 湿球温度 | ℃ | 水で湿らせた温度計が示す温度。蒸発冷却量が反映される |
| v | 比容積 | m³/kg | 乾き空気1 kgが占める体積 |

## 🔢 計算式・計算根拠

### ① 飽和水蒸気圧　pₛ [kPa]

Buck方程式（ASHRAE推奨に準拠）を使用：

```
pₛ(T) = 0.61121 × exp( (18.678 − T/234.5) × T/(257.14 + T) )
T : 乾球温度 [℃]
```

### ② 絶対湿度　W [kg/kg']

```
pv = RH/100 × pₛ(DB)          ← 実水蒸気分圧
W  = 0.62198 × pv / (P − pv)  ← P:大気圧[kPa]
```

### ③ 相対湿度　RH [%]

```
pv = W × P / (0.62198 + W)
RH = pv / pₛ(DB) × 100
```

### ④ 露点温度　DP [℃]

実水蒸気分圧 pv を求め、pₛ(T)=pv となる T をNewton法で逆算。  
逆方向（DP→W）は大気圧だけで一意に決まるため、DP単独入力でWを即時算出可能：

```
W  → DP : pv = W×P / (0.62198+W),  DP = pₛ⁻¹(pv)  ← Newton法
DP → W  : pv = pₛ(DP),  W = 0.62198×pv / (P−pv)   ← 直接計算
```

### ⑤ 比エンタルピー　h [kJ/kg]

JIS B 8628 / ASHRAE Fundamentals 準拠：

```
h = 1.006×DB + W×(2501 + 1.86×DB)
  ↑乾き空気顕熱  ↑水蒸気潜熱  ↑水蒸気顕熱
```

### ⑥ 湿球温度　WB [℃]

簡略Sprung式（温度補正項を省略）を使用。DB・W が既知のとき WB を二分法で求解：

```
W = Wₛ(WB) − A × (DB − WB)
Wₛ(WB) : WBにおける飽和絶対湿度
A = 0.000412 [1/℃]  ← Cpa/λ ≒ 1.006/2501 に相当
DB, W が既知のとき DP ≤ WB ≤ DB の範囲を二分法で求解
```

### ⑦ 比容積　v [m³/kg]

理想気体の状態方程式から：

```
v = 0.2871×(DB+273.15)×(1 + 1.6078×W) / P
0.2871 : 乾き空気のガス定数 Ra/1000 [kJ/(kg·K)]
1.6078 : Ra/Rv = 287.058/461.5
```

### ⑧ 逆算・特殊ケース

DB以外の2変数が既知の場合、二分法（bisection）でDBを求めた後、上記①〜⑦を適用します。探索範囲は −30〜80℃。  
DP単独の場合は DP→W の直接変換（大気圧のみで決まる）を行います。

## 📊 空気線図・比較チャート

- **空気線図**：計算タブの下部にリアルタイム表示。計算結果の状態点を●でプロットします。表示範囲は乾球温度 −15〜50℃、絶対湿度 0〜40 g/kg'。
- **比較チャート**：履歴タブで保存した条件を最大5点まで選択して重ねてプロットできます（①〜⑤で色分け表示）。
- **選択操作**：履歴アイテムをタップして選択・解除。番号はタップした順に付与されます。
- **ツールチップ**：比較チャートの点をタップすると、その条件の詳細（DB・RH・W・DP・h・WB）が表示されます。
- **画像保存**：空気線図・比較チャートともに**長押し / ダブルクリック**で画像（PNG）として保存できます。

## ⚠️ 計算精度について

- 飽和水蒸気圧はBuck方程式（誤差 <0.01%）を使用しています。
- 湿球温度は簡略Sprung式（A=0.000412）を使用しており、参照ソフト値と±0.02℃以内で一致します。
- 精密な空調設計では ASHRAE Handbook of Fundamentals または JIS B 8628 の数表との照合を推奨します。
