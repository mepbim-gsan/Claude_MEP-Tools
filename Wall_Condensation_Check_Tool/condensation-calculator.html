#材料厚(mm)熱抵抗界面温度判定

壁の結露計算ツール — 利用マニュアル

ver 1.1 　計算手法・機能説明・操作ガイド

📌 ツール概要

本ツールは、建築壁体の定常状態における結露リスクを評価するためのWebツールです。ISO 13788 および グラスコ法（Glaser Method）に準じた手法で、温度分布・水蒸気圧分布を計算し、表面結露・壁体内結露の有無を判定します。

単一のHTMLファイルとして動作し、インターネット接続不要でPCおよびスマートフォンから利用できます。

🔢 計算フロー

  1. 室内外の温度・湿度を入力し、各層の材料と厚みを設定する。
  2. 各層の熱抵抗 R を算出し、壁体全体の温度分布を求める。
  3. 各層の透湿抵抗 SD を算出し、水蒸気圧分布を求める。
  4. 各界面の温度から飽和水蒸気圧を求め、実水蒸気圧と比較する。
  5. 室内側表面温度と室内空気の露点温度を比較し、表面結露リスクを判定する。

🌡 熱移動の計算（温度分布）

各層の熱抵抗

Ri = di / λi　[m²K/W]
d : 層厚 (m)　λ : 熱伝導率 (W/mK)

表面熱抵抗（固定値）

Rsi = 0.13 m²K/W　（室内側）
Rso = 0.04 m²K/W　（室外側）ISO 6946 準拠

壁体全熱抵抗と界面温度

Rtotal = Rsi + Σ Ri + Rso
Tx = Ti − (Ti − To) × ΣRx / Rtotal
Ti : 室内温度　To : 外気温度　ΣRx : 室内側からの累積熱抵抗

熱橋補正（熱橋部モード）

Ri,補正 = Ri × 1.3
柱・スタッド等の熱橋により断熱性能が低下する部位に適用

💧 湿気移動の計算（グラスコ法）

透湿抵抗 SD

SDi = μi × di　[m]
μ : 透湿抵抗係数（無次元）　d : 層厚 (m)

水蒸気圧分布（定常・線形補間）

Pv,x = Pv,i − (Pv,i − Pv,o) × ΣSDx / SDtotal
Pv,i = psat(Ti) × RHi　　Pv,o = psat(To) × RHo

飽和水蒸気圧（マグヌス式）

psat(T) = 610.78 × exp( 17.27T / (T + 237.3) )　[Pa]
T : 温度 (°C)

壁体内結露の判定

Pv,x > psat(Tx)　→ 結露発生
各界面において実水蒸気圧が飽和水蒸気圧を超えた場合に結露と判定

🧊 表面結露・カビリスクの判定

室内側表面温度

Tsi = Ti − (Ti − To) × Rsi / Rtotal

温度係数 fRsi

fRsi = (Tsi − To) / (Ti − To)
ISO 13788 の表面温度係数。1に近いほど断熱性能が高い。

室内空気の露点温度（マグヌス逆算）

Tdew = 243.04 × [ln(RH) + 17.625T/(243.04+T)] / [17.625 − ln(RH) − 17.625T/(243.04+T)]

表面結露リスク判定

Tsi < Tdew　→ 表面結露・カビリスクあり
⚠ カビの発生はJIS A 1470等において相対湿度80%以上の状態が継続する場合にリスクが高まるとされています。本ツールの判定は定常条件での参考値です。

⚙ 機能説明

🌡 環境プリセット UI
標準(冬) / 冬最低気温 / 猛暑(40°C) / 一般夏期の4種類の代表的な気象条件をワンタッチで設定できます。手動入力も可能です。
🧱 壁構成プリセット UI
木造軸組・2×4・RC造など日本住宅でよく使われる6種類の標準構成を収録。「📋 プリセット」から追加・削除・カスタム登録が可能です。
🔧 材料マスタ編集 UI
λ・μ値の変更、材料の追加・削除ができます。メーカーカタログ値への差し替えなど、実務仕様に合わせたカスタマイズが可能です。
📊 温度・露点グラフ 計算
壁体断面の温度分布（赤実線）と露点温度分布（青破線）を重ねて表示。結露が発生する界面は赤塗り●で強調表示されます。
⬇ JSON保存 / ⬆ JSON読込 入出力
環境設定・壁構成・材料マスタ・壁構成プリセットをすべて含む1つのJSONファイルで保存・復元できます。チームでの設定共有に活用できます。
🔄 解析モード切替 計算
「一般断熱部」と「熱橋部（柱）」を切り替えられます。熱橋部モードでは熱抵抗に補正係数 1.3 を乗じて、柱部位等での性能低下を模擬します。

⚠ 計算上の制限・注意事項

定常計算：本ツールは定常状態（温湿度が一定の条件）を前提とした計算です。実際の建物では温湿度は時間変動するため、本ツールの結果はリスク評価の参考値としてお使いください。

1次元計算：壁厚方向のみの1次元熱湿気移動を仮定しています。コーナー部・開口部周りなど2次元的な熱橋の影響は考慮されません。

熱橋補正：熱橋部モードの補正係数 1.3 は簡易的な値です。より精密な評価はISO 10211に基づく2次元数値計算が必要です。

μ値：透湿抵抗係数は材料・製品によって幅があります。重要な検討ではメーカー実測値を使用してください。

夏型逆結露：夏期に外側から湿気が浸入する「逆結露」は本ツールでは自動判定されません。夏期条件（猛暑プリセット等）を手動で設定して確認してください。
