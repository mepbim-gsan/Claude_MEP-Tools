天井懐・有効高さ計算ツール — 計算根拠

📌 概要

建築・設備設計の初期段階において、階高から各部寸法（スラブ・スラブ下げ・梁・設備スペース・天井）を積み上げた断面構成を可視化し、梁下有効スペース・天井高・必要階高のいずれかを算出するツールです。最大4パターンの同時比較に対応します。

⚙️ 計算モード

上部バーのモード切替で算出対象を選択します。

モード固定入力算出
梁下有効算定階高・天井高梁下有効スペース
天井高算定階高・梁下有効天井高
階高算定梁下有効・天井高必要階高

🔢 計算式

共通：梁突出寸法（BD_net）

BD_net = max(BD + FC − embed, 0) BD : 梁成（スラブ天端〜梁下端） FC : 耐火被覆厚（S造のみ。RC造は 0） embed : スラブへの飲み込み量

梁下有効算定モード（天井高固定 → 梁下有効を算出）

天井懐 = (SH − drop − ST) − CL 梁下有効 = 天井懐 − BD_net − CF

天井高算定モード（梁下有効固定 → 天井高を算出）

天井懐 = BD_net + MEP + CF 天井高 = SH − drop − ST − 天井懐

階高算定モード（積み上げ → 必要階高を算出）

天井懐 = BD_net + MEP + CF 必要階高 = drop + ST + 天井懐 + CL

※ drop（スラブ下げ量）：上階FLからスラブ天端を下げる寸法。階高 SH は上階FL〜下階FL で変わらないが、有効梁下高さの基準はスラブ下面（= 上FL − drop − ST）となる。

📋 入力項目一覧

記号項目名説明単位
SH階高上階FL〜下階FL（スラブ下げ前の基準距離）mm
STスラブ厚上階スラブの構造厚mm
dropスラブ下げ量上階FLからスラブ天端を下げる量。0のとき上FLライン非表示mm
BD梁成スラブ天端〜梁下端の全高（構造梁せい）mm
FC耐火被覆厚S造梁への吹付被覆厚。RC梁の場合は入力不要（無効）mm
embedスラブへの飲み込み梁天端がスラブ内に食い込む量。BD_net を減少させるmm
MEP梁下有効スペースダクト・配管・電気ラック等の設備スペース確保高さmm
CL天井高FL〜天井仕上げ下端（FL+○○○）mm
CF天井材厚天井ボード・下地・吊材を含む仕上げ材の厚さmm

🖥️ 断面グラフィック

  • 上階スラブ（コンクリートハッチ）・梁・設備ゾーン・天井板・有効高さ背景を断面図として描画します。
  • スラブ下げ（drop > 0）：上階FLを青点線で表示。スラブはFL基準からdrop分下に配置。階高の赤寸法線は上FL〜下FLを示します。
  • 飲み込み（embed > 0）：梁はスラブ内まで描画され、スラブで覆われた部分は隠れます。スラブ内の飲み込み範囲を点線矩形で示します。有効な梁下突出量はBD_netです。
  • S造梁：H形鋼断面を模式表示。耐火被覆（FC > 0）はH形鋼の全周（上フランジ上面を除く）を黄土色で描画し、選択した耐火等級に応じて表示厚が変化します。梁下有効ゾーンは耐火被覆の下端から天井板上端までです。
  • RC梁：コンクリート断面（スラブと色調差あり）。耐火被覆は不要のため入力無効。
  • 寸法線：赤＝算出対象、グレー＝参考寸法（スラブ下げ量含む）。

🔥 耐火被覆の選択

S造梁の耐火被覆厚はプルダウンで選択します（0 / 25 / 45 / 60 mm）。

選択値耐火等級断面図の表示厚BD_netへの影響
0 mm被覆なしなしBD + 0 − embed
25 mm（1時間）1時間耐火細めBD + 25 − embed
45 mm（2時間）2時間耐火中程度BD + 45 − embed
60 mm（3時間）3時間耐火太めBD + 60 − embed

※ RC梁は耐火被覆不要のため、RC選択時は入力欄が無効になります。
※ 断面図の被覆表示厚は視認性のため実寸比例ではありません（25→細 / 45→中 / 60→太）。
